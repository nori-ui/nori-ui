## At a glance

- A [`TextInput`](/docs/components/text-input) that masks its value and has a button to show or hide it.
- Takes every `TextInput` prop (`value`, `onChangeText`, `placeholder`, `disabled`, `leading`, `className`, `containerClassName`, `id`, `name`, `testID`, …) except `trailing`, `secureTextEntry`, `multiline`, and `numberOfLines`. The toggle button occupies the trailing slot, and the component controls masking.
- Visibility is uncontrolled by default (`defaultVisible`) or controlled with `visible` and `onVisibleChange`.
- Sets `autoCapitalize="none"`, `autoCorrect={false}`, `spellCheck={false}`, and `autoComplete="current-password"`. All four can be overridden.
- Works inside [`Field`](/docs/components/field) for label, description, error, and accessibility wiring.

## Usage

Wrap the input in `Field` to give it a visible label.

```tsx
import { Field, PasswordInput } from '@nori-ui/core';
import { useState } from 'react';

export const Example = () => {
    const [password, setPassword] = useState('');

    return (
        <Field label="Password">
            <PasswordInput value={password} onChangeText={setPassword} />
        </Field>
    );
};
```

Without a `Field`, give the input an accessible name with `aria-label`:

```tsx
import { PasswordInput } from '@nori-ui/core';

export const Example = () => <PasswordInput aria-label="Password" placeholder="Password" />;
```

## `autoComplete`

The default is `autoComplete="current-password"`, which is right for sign-in forms. On a sign-up or change-password form, pass `autoComplete="new-password"` so password managers offer to generate and save a password.

```tsx
import { Field, PasswordInput } from '@nori-ui/core';

export const Example = () => (
    <Field label="New password" description="At least 12 characters.">
        <PasswordInput autoComplete="new-password" />
    </Field>
);
```

## `defaultVisible`

Uncontrolled visibility. The component keeps the state itself. `defaultVisible` sets the initial state. Default: `false` (masked).

```tsx
import { Field, PasswordInput } from '@nori-ui/core';

export const Example = () => (
    <Field label="Wi-Fi password">
        <PasswordInput defaultVisible defaultValue="correct horse battery staple" />
    </Field>
);
```

## `visible` and `onVisibleChange`

Controlled visibility. `visible={true}` shows the value as plain text. `visible={false}` masks it. `onVisibleChange` is called with the next visibility when the user presses the toggle. The component does not change visibility by itself in this mode: update `visible` in the handler.

```tsx
import { Field, PasswordInput } from '@nori-ui/core';
import { useState } from 'react';

export const Example = () => {
    const [visible, setVisible] = useState(false);

    return (
        <>
            <Field label="Password">
                <PasswordInput visible={visible} onVisibleChange={setVisible} autoComplete="new-password" />
            </Field>
            <Field label="Repeat password">
                <PasswordInput visible={visible} onVisibleChange={setVisible} autoComplete="new-password" />
            </Field>
        </>
    );
};
```

## With an error

`Field` marks the input as invalid and links the error text to it.

```tsx
import { Field, PasswordInput } from '@nori-ui/core';

export const Example = () => (
    <Field label="Password" error="That password is too short.">
        <PasswordInput defaultValue="short" autoComplete="new-password" />
    </Field>
);
```

## `disabled`

`disabled` blocks the input and the toggle button. A disabled `Field` has the same effect.

```tsx
import { Field, PasswordInput } from '@nori-ui/core';

export const Example = () => (
    <Field label="Password" disabled>
        <PasswordInput defaultValue="locked" />
    </Field>
);
```

## `ref`

`ref` points to the underlying text input. Use it to call `focus()` or `blur()`.

```tsx
import { Button, PasswordInput, VStack } from '@nori-ui/core';
import { useRef } from 'react';
import type { TextInput } from 'react-native';

export const Example = () => {
    const inputRef = useRef<TextInput>(null);

    return (
        <VStack gap={2}>
            <PasswordInput ref={inputRef} aria-label="Password" />
            <Button onPress={() => inputRef.current?.focus()}>Focus the password field</Button>
        </VStack>
    );
};
```

## Focus behavior

- Web: clicking or tapping the toggle does not move focus. If the input was focused, it stays focused and the caret stays in place. A keyboard user who tabs to the toggle keeps focus on the toggle and can press it again.
- Native: if the input was focused when the toggle was pressed, the input is focused again afterwards, so the keyboard stays open.

## Accessibility

- The toggle is a real button. On web it is a `<button>` element and a tab stop after the input. Enter and Space activate it.
- Web: the button's accessible name is always the `input.passwordShow` dictionary key ("Show password"). Its state is exposed with `aria-pressed`: `true` while the password is visible.
- Native: there is no pressed state, so the accessible name changes instead. It is `input.passwordShow` ("Show password") while the value is masked and `input.passwordHide` ("Hide password") while it is visible.
- The button is 28px square. On native its touch target is extended to 44px.
- Keyboard focus on the button draws a 2px outline in the primary interactive color.
- Inside `Field`, the input receives `id`, `aria-labelledby`, `aria-describedby`, `aria-invalid`, and `aria-required` from the field.

Translate the labels through the provider:

```tsx
import { Field, NoriProvider, PasswordInput } from '@nori-ui/core';

export const Example = () => (
    <NoriProvider i18n={{ 'input.passwordShow': 'Passwort anzeigen', 'input.passwordHide': 'Passwort verbergen' }}>
        <Field label="Passwort">
            <PasswordInput />
        </Field>
    </NoriProvider>
);
```
